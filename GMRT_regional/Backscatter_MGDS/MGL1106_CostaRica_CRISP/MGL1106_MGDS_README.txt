DATA SET URL: https://www.marine-geo.org/tools/datasets/21024

>>>> DATA SET DESCRIPTION <<<<
    High-resolution 5m backscatter grid derived using novel range-angle techniques from Kongsberg EM122 multibeam data. Offshore Costa Rica, NSF MARGINS Central America focus site. Data collected in 2011 during the Langseth CRISP 3-D MCS cruise MGL1106 (investigators Jared Kluesner, Nathan Bangs, Cesar Ranero, Kirk McIntosh, Eli Silver).

>>>> DATA SET DETAILS <<<<
