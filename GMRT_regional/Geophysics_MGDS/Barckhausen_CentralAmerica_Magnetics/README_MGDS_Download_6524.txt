>>>> DATA SET DESCRIPTION <<<<
    This data set was acquired with a ship-based Magnetometer assembled as part of the 1998 Central_America:Magnetics_Barckhausen data compilation (Chief Scientist: Dr. Udo Barckhausen). These data files are of NetCDF Grid format and include gridded Magnetic Anomaly (IGRF Removed) data and were processed after data collection. This data was cited by Barckhausen et al., 2001.

>>>> DATA SET DETAILS <<<<
    Magnetic anomaly compilation grid
