Select one or more CSVs at once (e.g. MTsites.csv + DredgeSites.csv from MT_dredging_coords/) -- lat/lon columns required, status column optional. Each file becomes its own row above with a checkbox, like the dataset layers -- loading a new file adds it alongside what's already there; loading the same file name again replaces just that one. Marker shape comes from the file name ("dredge"/"mt"); colour comes from status. Points snap onto the currently-visible seafloor surface.
104 stations from Site_Maps/Previous_Dredges_Compiled.csv (same symbols as the previous-dredge maps). Shape = cruise. By recovery: green = glass, grey = no glass, X = no rock. By cruise: filled = glass, open = no glass. Untick a row to hide it.
One planned on-bottom track per dredge site, from MT_dredging_coords/DredgeLines.csv. Arrow = tow direction (start, green, to end, red). Orange = auto first guess (1 km through the site, the direction that climbs most without cresting the edifice), yellow = auto but flat (under 3 deg: direction weakly constrained), magenta = drawn/edited by hand. "Draw line": pick a site, click the start, then the end on the surface. "Save to repo" writes the CSV (old copy kept in MT_dredging_coords/backups/) and recomputes depths and slopes from the finest grid.
Optional. Needs the viewer started with python3 run_viewer.py --ship-feed (listens on UDP 55000 for GPS and 55001 for heading, NMEA). Updates once a minute while ticked.
"Colour" is an RGBA picture of the mesh (for GIS/visual reference). "Elevation" is a single-band float32 GeoTIFF of real depth/elevation in metres (NaN nodata) -- use this for slope/roughness/terrain analysis. Geophysics layers are skipped in Elevation format (they drape on borrowed terrain, not their own data).
Exports a georeferenced 2D GeoTIFF of every checked (and format-eligible) dataset, composited coarse-to-fine. "Select region" drags a rectangle on the map to export just that area.
Cuts the selected region (or, if none, the current view) straight out of the original grid file: 1 pixel = 1 grid cell, no resampling, the grid's own CRS. Downloads a zip with an elevation GeoTIFF (float32, metres), a colour GeoTIFF for chart/nav display (using the colour map picked in that layer's legend, if any), a slope GeoTIFF + picture, a map PNG and an info file. Needs run_viewer.py.
